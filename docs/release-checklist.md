# Production release checklist

- [ ] governance owners and security contact are published;
- [ ] privacy notice and retention schedule are approved;
- [ ] OpenAPI, JSON Schemas and deployment guide are versioned;
- [ ] migrations and configuration are backed up;
- [ ] HTTPS, HSTS, CSP, secure cookies and no-store controls verified;
- [ ] non-PII export sample and redaction tests verified;
- [ ] free-text moderation and incident-response process enabled;
- [ ] accessibility and VAPT retests completed;
- [ ] release tag, checksum, changelog and rollback plan published.
