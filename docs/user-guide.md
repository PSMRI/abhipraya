# User guide

## For administrators

1. Open the application URL and sign in with an authorised account.
2. Use **QR Management** to select a facility and department, then generate the public survey link and QR poster.
3. Display the QR code at the selected facility.
4. Use the dashboard and reports to review response trends and identify improvement priorities.
5. Use CAPA to document corrective and preventive actions for low-scoring indicators.
6. Use **Social Audit** to generate a time-limited community-feedback QR link when that workflow is required.

## For survey participants

1. Scan the facility QR code.
2. Allow location access when prompted. The survey checks that the device is within the configured facility radius.
3. Select English or Hindi.
4. Answer each question and submit feedback.

Feedback is intended to be anonymous. Do not enter personal or medical information in survey responses.

## Social Audit

Social Audit is a separate community survey. Administrators select a facility and survey date, then generate a QR link. Ordinary facility links expire after four hours; test NIN `1234567890` does not expire. Participants can answer in English or Hindi with Hindi audio support. One browser device can submit once per QR link for ordinary facilities; the test NIN allows repeat testing. See the [Social Audit QR survey guide](user/social_audit.md) for the full workflow and audit-data rules.

## Account assistance

Use **Forgot password?** to see the administrator-support notice. Password resets are handled by the system administrator.
