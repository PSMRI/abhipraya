# Digital Public Good readiness

The Digital Public Goods Alliance (DPGA) Standard uses nine indicators: SDG relevance, open licensing, clear ownership, platform independence, documentation, non-PII data extraction, privacy and applicable laws, open standards and best practices, and do-no-harm/privacy and security.

## Current assessment

| Indicator | Status | Evidence or next action |
| --- | --- | --- |
| SDG relevance | Needs documented evidence | Link health-feedback outcomes to SDG 3 and local programme objectives. |
| Open licensing | Ready | GPL-3.0 is an OSI-approved open-source license. |
| Clear ownership | Needs action | Publish a maintainer, copyright, trademark, and governance statement. |
| Platform independence | Partial | PHP/IIS deployment is documented; add Linux web-server deployment guidance. |
| Documentation | Ready foundation | This GitBook guide provides user, developer, deployment, and security documentation. |
| Non-PII data extraction | Needs evidence | Publish an export/data dictionary and document anonymisation guarantees. |
| Privacy and law | Needs action | Publish a privacy notice, retention policy, lawful-use policy, and grievance contact. |
| Open standards | Partial | Document API contracts, interoperability formats, and accessibility conformance. |
| Privacy, security, and do no harm | Partial | VAPT controls are documented; complete retesting and establish incident response. |

## Before DPGA nomination

Publish the missing governance and privacy material, document SDG impact, complete a production security retest, and submit only the core open-source solution for assessment. The DPGA assesses the core solution, not each local implementation.

See the [DPG Standard](https://www.digitalpublicgoods.net/standard) for the official requirements.
