# WCAG and web platform compliance

## Target

Abhipraya should meet WCAG 2.2 AA expectations for public and administrator journeys where practical.

## Required checks

- Keyboard-only navigation reaches all controls and visible focus is retained.
- A skip link reaches main content.
- Form controls have visible labels and error messages are understandable.
- Colour is not the only indication of priority or status; icons and text accompany it.
- Rating stars include text values for assistive technologies.
- Tables have headers and responsive alternatives where needed.
- Touch targets are large enough for mobile public survey use.
- Text enlarges through browser zoom without loss of core function.
- Hindi and English text render correctly.
- Dropdown search and filters remain usable by keyboard.

## Security-related web platform checks

- CSP blocks inline script and style injection.
- API responses do not expose stack traces.
- Protected administrator pages redirect unauthenticated users.
- Cache-control protects authenticated page content.
