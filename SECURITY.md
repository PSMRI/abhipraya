# Security policy

Report suspected vulnerabilities privately to [abhipraya@piramalswasthya.org](mailto:abhipraya@piramalswasthya.org), the Abhipraya Team's public security contact. Do not post exploit details, credentials, personal data, or proof-of-concept attacks in public issues.

Include the affected URL or component, reproduction steps, impact, and any suggested mitigation. The maintainer should acknowledge reports, assess impact, track the finding to remediation or approved risk acceptance, and coordinate disclosure after a fix or mitigation is available.
