Abhipraya is a secure, geo-verified, and user-friendly feedback system for collecting structured responses from healthcare facility visitors.

Open administrator portal →Read user guide
  • Anonymous feedback
  • 200 m GPS verification
  • Multilingual surveys

Objective

Make every visitor's experience count.

Use facility-linked QR codes, dynamic questionnaires, and location validation to gather dependable feedback and translate it into measurable service improvement.

Key features implemented

A complete feedback journey, built around the facility.

01

NIN-linked QR codes

Facility details are auto-fetched from the NIN embedded in each QR survey URL.

02

Facility information

Name, type, coordinates, and location context load from JSON configuration.

03

Dynamic multilingual surveys

Questions, answers, labels, and acknowledgement messages are JSON-driven.

04

GPS verification

Submission is permitted only within the configured 200 metre radius.

05

Duplicate prevention

Device identity, IP address, and a 24-hour window restrict repeat entries.

06

Real-time submission

Fetch API requests provide a seamless submission experience.

07

Thank-you confirmation

A clear acknowledgement confirms successful feedback submission.

How it works

Seven steps from scan to insight.

  1. Scan QR codeOpen the NIN-linked survey URL.
  2. Load facilityResolve facility name and coordinates.
  3. Load questionsRead the dynamic JSON questionnaire.
  4. Verify locationConfirm the visitor is within 200 m.
  5. Check duplicateApply device, IP, and time controls.
  6. Submit responseSend answers and location securely.
  7. AcknowledgeShow the thank-you confirmation.

Technical highlights

Configurable by design.

  • JSON-driven questions, answers, buttons, and facility data
  • GPS-based location verification at ≤ 200 m
  • Duplicate controls using device identity, IP, and time window
  • Versioned PHP APIs with CSRF, secure sessions, CSP, and login throttling
