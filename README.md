# Abhipraya

Abhipraya is an open-source, multilingual public-feedback platform for health facilities. It supports QR-led surveys, location-aware submissions, department reporting, and administrative management.

## Documentation

The GitBook-ready documentation is in [docs](docs/README.md). It includes user and developer guides, security controls, deployment notes, and a Digital Public Goods readiness checklist.
